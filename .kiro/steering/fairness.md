# 공정성·법적 기준 (반드시 지킬 것)

## 표현
- "가짜 리뷰", "조작", "사기" 같은 단정 표현을 UI 문구, LLM 프롬프트, 응답 어디에도 쓰지 않는다.
- 판정은 "대가성 가능성"으로 표현하고, 근거 문장(`evidence`)을 함께 보여준다.
- 숨은 얼룩(`hidden`)은 추정이라는 점을 UI에서 구분해 표시한다 (🟡, "의심" 수준의 문구).
- 영수증에는 항상 기준 리뷰 수(`basedOn`)를 표시한다.

## 근거
- 요약의 모든 항목(`pros`, `cons`, 주제 요약)은 실제 입력 리뷰의 ID(`reviewIds`)를 하나 이상 가진다.
- LLM 응답에 입력에 없는 리뷰 ID가 있으면 버린다. 근거가 없는 요약 항목은 표시하지 않는다.
- `evidence`는 원문 리뷰에 실제로 있는 문장이어야 한다.

## 데이터 수집
- 서버에서 크롤링하지 않는다. 사용자가 보고 있는 페이지에서, 사용자가 실행할 때만 리뷰를 읽는다.
- 쿠팡 어댑터: 사용자가 버튼을 눌렀을 때만, 최대 15페이지, 요청 간격 1초. 실패하면 화면에 보이는 리뷰만 분석한다.
- 리뷰를 서버나 스토리지에 저장하지 않는다. 세탁이 끝나면 폐기한다. 로그에도 리뷰 원문을 남기지 않는다.

## 가상 플랫폼과 데이터
- 가상 플랫폼은 실존 서비스의 디자인, 로고, 브랜드명을 쓰지 않는다.
- 리뷰 데이터는 AI로 생성한 가상 데이터다. 실존 브랜드, 업체, 인물을 등장시키지 않는다.

## 근거 법령
- 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」: 대가성 리뷰는 그 사실을 밝혀야 한다.
