# 제품: 별점세탁소

쿠팡 상품 페이지에서 사이드 패널을 열면 리뷰를 자동으로 읽어 온다. 시작 화면에서 기본 세탁, 섬세 세탁, 부분 세탁 중 하나를 고른다. 세탁하면 체험단, 제품 제공 같은 대가성 리뷰(얼룩)를 걷어낸 세탁 후 평점과, 얼룩을 뺀 리뷰로만 만든 세탁 후 요약을 보여준다. 자유로운 문장으로 질문하면 세탁된 리뷰 중 조건에 맞는 리뷰 원문만 사이드 패널에 띄우고 요약한다. 그 목록에 다시 질문해서 원하는 리뷰를 계속 좁혀 갈 수 있다.
Kirothon 2026 출품작이며 주제는 "내 일상에 바로 적용할 수 있는 서비스"다. 팀 규랑이 탐험대(재현, 규리, 주영, 정민).
쿠팡과 제휴하지 않은 비공식 도구다. 쿠팡 상품 페이지에서만 동작한다.

## 사용자
- 쿠팡에서 리뷰와 별점을 보고 물건을 사는 사람
- 공통 고민: 별점이 대가성 리뷰로 부풀려져 있고, 궁금한 것 하나를 찾으려고 리뷰 수백 개를 스크롤해야 한다

| 🔴 확실한 얼룩 | "리뷰 이벤트 참여", "리뷰 작성 시 사은품" 등 판매자 이벤트 명시 | `review_event` |

## 세탁소 용어 (코드, UI, 문서에서 이 용어를 일관되게 쓴다)
| 용어 | 의미 | 코드 식별자 |
|---|---|---|
| 입고 | 사이드 패널을 열면 페이지에서 리뷰를 읽어 오는 단계 | `intake`, 입고 어댑터 |
| 얼룩 | 대가성 리뷰 | `stain` |
| 확실한 얼룩 🔴 | 플랫폼 체험단 표시, 원문에 대가성이 명시된 리뷰 | `stain: "certain"` |
| 의심 얼룩 🟡 | 명시는 없지만 대가성 신호가 있는 리뷰 | `stain: "suspected"` |
| 깨끗한 리뷰 | 얼룩이 아닌 리뷰 | `stain: "none"` |
| 얼룩 신호 | 판정 이유의 종류 | `signal` |
| 근거 문장 | 판정 근거가 된 원문 문장 | `evidence` |
| 기본 세탁 | 확실한 얼룩만 빼는 세탁. 시작 화면 버튼 | `POST /wash`, `strict: false` |
| 섬세 세탁 | 의심 얼룩까지 빼는 세탁. 시작 화면 버튼 | `POST /wash`, `strict: true` |
| 세탁 전 / 세탁 후 평점 | 입고한 리뷰 전체의 평균 / 얼룩을 제외한 평균 | `before` / `after` |
| 세탁 후 요약 | 얼룩을 뺀 리뷰로만 LLM이 쓴 2~3문장 요약. 문장마다 근거 리뷰 ID | `summary` |
| 세탁 요청 | 부분 세탁에서 사용자가 입력하는 자유로운 문장 | `request` |
| 부분 세탁 | 세탁된 리뷰를 문장으로 거르고, 결과에 다시 질문해 계속 좁혀 가기 | `POST /ask` |
| 조건 | 질문에서 뽑은 거르는 기준. 정해진 조건(별점, 기간, 사진, 정렬, 구매 옵션, 단어)과 의미 조건(주제, 사용자 상황) | `conditions` |
| 조건 칩 | 쌓인 단계를 보여주는 표시 (`사진 있음 31 › 3점 이하 · 발열 4`) | `label`, 단계 스택 |
| 리뷰 목록 | 사이드 패널에 뜨는 현재 단계의 리뷰 원문 | `matches` |
| 세탁 영수증 | 결과 카드 (입고 범위, 얼룩 수, 평점, 세탁 후 요약, 장점·단점) | `receipt` |
| 세탁 태그 | 리뷰 카드에 붙는 판정 배지와 근거 | `tags` |
| 리뷰 카드 | 사이드 패널의 리뷰 한 개 (별점, 작성일, 구매 옵션, 사진, 본문 전체, 세탁 태그. 작성자 이름 없음) | `ReviewCard` |

## 세탁 방식
| 방식 | 사용자 동작 | 평점·요약에서 빼는 것 | 결과 |
|---|---|---|---|
| 기본 세탁 | 시작 화면 🧺 버튼 | 🔴 확실한 얼룩 | 세탁 후 평점, 세탁 후 요약, 장점/단점. 🟡는 태그만 붙인다 |
| 섬세 세탁 | 시작 화면 🔍 버튼 | 🔴 + 🟡 | 의심 얼룩도 뺀 평점과 요약 |
| 부분 세탁 | 시작 화면 🎯 버튼 또는 영수증 아래 "원하는 리뷰 찾기" → 문장형 질문, 결과에 다시 질문 | 직전 세탁과 같음 | 조건에 맞는 리뷰 카드 목록, 근거 문장, 평균 별점, 요약, 장점·단점. 질문할수록 목록이 좁아진다 |

- 기본 세탁과 섬세 세탁은 자연어 해석이 필요 없다. 버튼으로만 동작한다.
- 부분 세탁은 직전 세탁의 판정을 그대로 쓰고 다시 판정하지 않는다. 시작 화면에서 🎯를 고르면 기본 세탁을 먼저 자동으로 한다.
- 별점, 기간, 사진, 정렬, 구매 옵션, 정확한 단어 같은 정해진 조건은 코드가 거른다. LLM은 질문을 조건으로 바꾸고, 의미 조건("발볼 넓은 사람")만 판단한다.
- 기본·섬세 세탁 직후에도 세탁된 리뷰 목록을 보여준다. 얼룩으로 빠진 리뷰는 "빠진 리뷰 보기"로 따로 볼 수 있다.
- 리뷰 원문은 사이드 패널의 리뷰 카드로 모두 보여준다. 쿠팡 페이지에 태그를 붙이거나 쿠팡 화면을 스크롤하는 기능은 만들지 않는다 (쿠팡 화면에는 지금 페이지의 리뷰만 있다).
- 요약 문장을 누르면 패널 안에서 근거 리뷰 카드로 이동하고 근거 문장을 강조한다.
- 🟡 의심 얼룩은 모든 세탁에서 판정하고 태그를 붙인다.

## 시작 화면 (세탁 방식 고르기)
입고가 끝나면 사이드 패널에 세 버튼이 나온다. 버튼마다 무엇을 하는지 한 줄 설명과 예시를 항상 같이 보여준다.

```
🧺 리뷰 96개 입고 완료 (베스트 50 + 최신 50, 중복 4개 제외)
어떤 세탁을 할까요?

┌ 🧺 기본 세탁 ────────────────────────────┐
│ 체험단·제품 제공·리뷰 이벤트처럼 대가성이     │
│ 확실한 리뷰를 빼고 평점과 요약을 보여줘요.     │
│ 광고로 의심되는 리뷰는 표시만 해요.            │
└──────────────────────────────────────┘
┌ 🔍 섬세 세탁 ────────────────────────────┐
│ 기본 세탁에 더해, 광고로 의심되는 리뷰도       │
│ 빼고 계산해요. 의심은 추정이라 근거 문장을     │
│ 함께 보여줘요.                                │
└──────────────────────────────────────┘
┌ 🎯 부분 세탁 ────────────────────────────┐
│ 원하는 리뷰만 문장으로 찾아요.                 │
│ 예) "사진 있는 3점 이하 리뷰 중 발열 얘기"     │
│ 결과에 다시 질문해서 더 좁힐 수 있어요.        │
└──────────────────────────────────────┘
```

- 문구는 위와 같은 뜻을 유지한다. "가짜", "조작" 같은 단정 표현을 쓰지 않는다 (fairness.md).
- 🧺 기본 세탁: `/wash`(`strict: false`) → 영수증 화면.
- 🔍 섬세 세탁: `/wash`(`strict: true`) → 영수증 화면. 의심 얼룩에는 "의심" 표시와 근거 문장을 붙인다.
- 🎯 부분 세탁: 기본 세탁을 먼저 하고(이미 했으면 재사용) 바로 질문 창으로 간다. 질문 창 위에 "기본 세탁된 리뷰 N개 안에서 찾아요"를 표시하고, 예시 질문 3개를 칩으로 보여준다 (누르면 입력됨).
- 결과 화면 위쪽에는 항상 지금 방식(기본/섬세/부분)과 다른 방식으로 바꾸는 버튼을 둔다. 기본 ↔ 섬세 전환은 판정을 다시 하지 않는다 (`applyStrict`).
- 영수증 화면 아래에도 "🎯 이 결과에서 원하는 리뷰 찾기"를 둬서 바로 부분 세탁으로 이어지게 한다. 이때는 지금 방식(기본 또는 섬세)의 남은 리뷰 안에서 찾는다.
- 입고 중에는 세 버튼을 비활성화하고 진행률("입고 중 37/100")을 보여준다. 입고가 일부만 됐으면(`partial`) 버튼 위에 "일부 리뷰만 불러왔어요 (이유)"를 표시하고 그대로 진행할 수 있게 한다.
- 처음 쓰는 사람을 위해 각 버튼에 "?"를 두고, 누르면 세탁 전·후 평점이 무엇인지, 🔴🟡가 무엇인지 짧게 설명한다.

## 세탁 원칙
1. AI는 판정만, 숫자는 코드가 계산한다. 평점과 개수를 LLM에게 계산시키지 않는다.
2. 근거 없는 요약은 없다. 요약 문장마다 근거 리뷰 ID가 있어야 한다.
3. 정직하게 표시한다. 입고 범위("베스트순 50 + 최신순 50, 중복 제외 N개")를 밝히고, 의심 얼룩은 단정하지 않고 신호와 근거로만 보여준다.
4. 세탁 전 평점은 페이지에 표시된 평점이 아니라 입고한 리뷰로 계산한다. 페이지 평점은 참고용으로 같이 보여줄 수 있다.

## 평가자 체험 시나리오 (MVP의 기준)
1차 심사는 발표 없이 평가자가 레포와 확장을 직접 써 보고 평가한다. 아래가 README 안내만으로 끊김 없이 동작해야 한다.
1. Releases의 zip을 받아 크롬에 압축해제 확장으로 로드한다.
2. 쿠팡 상품 페이지(예시 상품)에서 툴바의 🧺 아이콘으로 사이드 패널을 연다 → 입고가 자동으로 시작되고 진행률("입고 중 37/100")이 보인다.
3. 시작 화면에서 세 버튼과 설명을 확인하고 🧺 기본 세탁 → 세탁 전 → 세탁 후 평점, 세탁 후 요약, 세탁된 리뷰 카드 목록. "빠진 리뷰 보기"에는 🔴🟡 태그와 근거가 붙은 카드. 요약 문장을 누르면 근거 리뷰 카드로 이동한다.
4. 위쪽의 🔍 섬세 세탁으로 바꾸기 → 의심 얼룩까지 뺀 평점과 요약 (다시 기다리지 않음).
5. 🎯 "이 결과에서 원하는 리뷰 찾기" → "사진 있는 리뷰만" → 조건 칩 `사진 있음 N ★평균`, 리뷰 카드 목록, 요약, 장점·단점.
6. 이어서 "그중에 3점 이하이고 발열 얘기한 것만" → 목록이 더 좁아지고, 리뷰마다 발열 문장이 강조된다. 칩의 ✕로 한 단계 뒤로 간다.

- 수치는 실제 페이지에서 코드가 계산한 값이다. README의 4.8 → 4.3은 예시다.
- 실패해도 화면이 멈추지 않아야 한다: 입고 중단, API 오류, 시간 초과 때마다 사이드 패널에 이유와 다음 행동을 보여준다.
