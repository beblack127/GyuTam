# 제품: 별점세탁소

체험단, 제품 제공, 리뷰이벤트 같은 대가성 리뷰(얼룩)를 걷어내고 세탁 후 평점과 근거 달린 요약을 보여주는 크롬 확장 프로그램이다.
Kirothon 2026 출품작이며 주제는 "내 일상에 바로 적용할 수 있는 서비스"다.

## 사용자
- 온라인 쇼핑 전에 리뷰와 별점을 보고 상품을 고르는 사람
- 음식점, 카페, 미용실을 리뷰로 고르는 사람
- 공통 고민: 별점이 대가성 리뷰로 부풀려져 있고, 궁금한 것 하나를 찾으려고 리뷰 수백 개를 스크롤해야 한다

## 세탁소 용어 (코드, UI, 문서에서 이 용어를 일관되게 쓴다)
| 용어 | 의미 | 코드 식별자 |
|---|---|---|
| 세탁 요청 | 사용자가 입력하는 자연어 질문 | `request` |
| 얼룩 | 대가성 리뷰 | `stain` |
| 눈에 띄는 얼룩 🔴 | 체험단·제공이 명시된 리뷰 | `stain: "explicit"` |
| 숨은 얼룩 🟡 | 명시는 없지만 대가성이 의심되는 리뷰 | `stain: "hidden"` |
| 깨끗한 리뷰 | 얼룩이 아닌 리뷰 | `stain: "none"` |
| 세탁 전 / 세탁 후 평점 | 원래 평점 / 얼룩을 제외하고 다시 계산한 평점 | `before` / `after` |
| 부분 세탁 | 특정 주제 리뷰만 골라 보기 | `topics` |
| 세탁 코스 | 해석된 세탁 요청 | `course` |
| 세탁 영수증 | 결과 카드 (기준 리뷰 수, 제거한 얼룩, 요약과 근거) | `receipt` |
| 세탁 태그 | 페이지의 각 리뷰 옆에 붙는 판정 배지 | `tags` |
| 입고 | 페이지에서 리뷰를 추출하는 단계 | `intake`, 입고 어댑터 |

## 세탁 코스
- 표준 코스: 얼룩 제외 평점 + 장점/단점 요약
- 부분 세탁: 주제(무게, 맛, 탈색 등) 관련 리뷰만 하이라이트하고 요약
- 이벤트 얼룩 제거: 음식점 등에서 리뷰이벤트 리뷰 제외
- 섬세 코스: LLM이 숨은 얼룩까지 판정하고 근거 문장 표시

## 세탁 원칙
1. AI는 판정만, 숫자는 코드가 계산한다. 평점과 개수를 LLM에게 계산시키지 않는다.
2. 근거 없는 요약은 없다. 요약 문장마다 근거 리뷰 ID가 있어야 한다.
3. 정직하게 표시한다. "최근 리뷰 N개 기준"을 밝히고, 단정 대신 "대가성 가능성 + 근거"로 표현한다.

## 데모 시나리오 (MVP의 기준)
1. 가상 리뷰 플랫폼의 보조배터리 상품 페이지(⭐4.7)에 들어간다.
2. 사이드 패널을 열면 "리뷰 55개 입고 완료"가 표시된다.
3. "제공받은 리뷰 빼고 평점 알려줘" → 4.7 → 4.1 애니메이션, 얼룩 리뷰에 🔴🟡 태그.
4. "무게 관련 리뷰만 요약해줘" → "무겁다 6건 / 적당하다 5건", 근거 클릭 시 해당 리뷰로 스크롤.
5. 장소 탭 음식점에서 "리뷰이벤트 빼고 맛 평가만".
6. 실제 쿠팡 상품 페이지에서도 세탁되는 장면.
